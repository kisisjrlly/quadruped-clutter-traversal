# 实验协议 v0.1

状态：预注册草案，须在正式测试前冻结；本启动包没有实验结果。

## 1. 数据与划分

使用固定 train/validation/test 场景清单。不能只换 seed 而保留相同模板；按布局生成家族、对象形状与关键几何条件隔离。正式测试前写入 scene manifest、配置 hash、机器人几何 hash、代码 SHA、策略权重 hash、环境和驱动版本。

同一场景对不同方法保存并恢复完整物理状态：机器人位置/速度/关节、每个物体位姿/速度、随机数状态、摩擦和感知噪声种子。只调用 reset(seed) 不自动证明完全配对。每种方法独立重置其记忆与 RNG，顺序随机化。

## 2. 原始记录

保存从启动前到终止后的时间同步传感器、完整关节/机身状态、命令、每个连杆碰撞、对象连续位姿、初态快照、地图年龄、规划时延、触发事件、人工干预和最终终止原因。碰撞后先记录终止状态再 reset。视频、模型与大日志放独立数据存储，仓库只保留 manifest 和校验和。

运行清单一项也不能丢：成功、超时、安全停止、传感器故障、人工接管、物体初态偏差都记录。排除无效试验的规则必须预先规定并保留原始记录。

## 3. 接触与扰动测量

仿真：使用物理引擎的全连杆 contact 事件，并做细杆穿透/时间步长/碰撞网格回归；移动/旋转统计采用整回合最大值。几何相交与接触力不完全等价，应记录适配器采用何种标准。

真机：结合俯视与侧视视频、物体位姿标记和可行的接触传感/力信号。某一路径只看物体有没有倒不能证明零接触。报告相机遮挡、分辨率、时间同步、检测阈值和人工审核一致性。接触覆盖不完整就将严格成功标为 unknown。

先做静置噪声、已知小位移和受控轻碰校准，再冻结阈值。当前配置中的 5 mm/2° 只是软件初值。指标还需包括禁止接触的部位分布、接触强度/持续时间（设备支持时）、物体最大位移/转角、倾倒数量和净空。

## 4. 统计与公平性

主表报告到达、环境保持、严格成功三种比例，以及 unknown/日志不全比例。严格成功保守下界 = 已证实成功数 / 全部预定有效试验数；乐观上界可另报 (成功+unknown)/总数，不能悄悄删除 unknown。

同时报告时间预算和完成时长分布，防止“永远停住”或“无限慢”刷安全。oracle 单列；真机与仿真单列；可行/不可行/未知场景单列。

用验证集试验估计方差与可实现效应，再确定正式样本量；没有数据时不承诺固定数量足够发表。以独立场景为重采样单位计算配对置信区间；同场景重复 rollout 不当成独立场景。报告训练 seed 差异、硬件/GPU小时、推理设备和 p95/p99 时延。

基线统一观测、底层控制能力、调参预算、时间限制。额外传感器/外部定位、不同速度和不同安全 margin 要分组，不可暗中给目标方法特权。

## 5. 关键消融

完整模型 vs 只碰撞机身；完整摆腿 vs 只落点；单帧 vs 运动补偿记忆；固定 margin vs 校准不确定性；主动观察 vs 同时间预算减速/固定观察动作（仅研究 H3 时）。每项消融保持其他条件不变。

## 6. 安全与停止

软质/无尖角、可替代的轻物体优先；不用玻璃和危险细杆。先低速、单障碍、现场监护和可靠急停；安全绳不能接触场景或被用来增加稳定性，若提供物理支撑需注明 assisted 并不计主轨道成功。安全失效回退需由实际平台验证，不能以直接断电作为通用安全策略。

## 7. 当前评测器的范围

`qct/evaluation.py` 只读取已经归约的 JSON 证据，执行判定并拒绝矛盾/非法输入。它不会校准传感器、计算原始轨迹的全程最大位移、自动发现撒谎的完整性标志或验证 hash 对应文件。证据绑定、采集与独立审计属于 M1/M3/M5；metadata 完整不等于证据真实。
