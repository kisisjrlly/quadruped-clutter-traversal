# 现有工作调研与差距分析（第 1 轮，2026-10-04）

## 1. 结论先行

项目不是“首个让机器狗不踩坏地面物品的系统”。**SemLoco 已经直接研究杂乱室内环境中低矮/易损物品的保护，使用 Isaac Lab，并报告真机实验**。局部三维记忆已有 NVM，模型规划结合学习跟踪已有 DTC，受限空间全身规划已有 Buchanan 等工作。仅把这些名称组合起来，不能构成已证实的新贡献。[R11][R12][R14][R01]

本轮保留的研究问题是：在**混合高度细小障碍、观测遮挡和低容错率**共同存在时，能否通过带观测时效/不确定性的几何记忆，联合约束足端、腿段、躯干的运动，显著降低接触，同时维持有效穿越率？这是待实验推翻或支持的假设，不是已经证明的空白。

## 2. 检索范围和证据等级

本轮沿四条线检索：精确落足与保护物品、全身/狭窄空间避障、视觉记忆与不确定性感知、动物敏捷/跑酷与规划学习混合。使用作者论文、arXiv、期刊原文、作者项目和 NVIDIA 官方源码；不以新闻报道或视频标题判断方法细节。参考条目稳定编号见 [来源账本](../references/verified_sources.json)。

检索问题包括 `quadruped fragile clutter foothold avoidance`、`quadruped whole body collision narrow spaces`、`visual locomotion volumetric memory`、`Isaac Lab contact report rigid objects`，并沿近邻论文引用补充。范围是截至本次检索可访问的公开材料，不是穷尽系统综述；未收录不代表不存在。全文、摘要、源码接口查阅、实装复现分开记录；**本项目尚未复现任一论文结果**。不跨论文直接比较成功率，因为场景、碰撞容忍度、任务终止和硬件不同。

## 4. 必须深入处理的五组比较

### 4.1 与 SemLoco：任务重叠必须正面承认

论文面向低矮物品、敏感设备和电缆，把语义安全性与高度分开，调整落足；还惩罚非足端身体碰撞。其训练先使用关闭物理碰撞的虚拟障碍，再切换到刚体障碍。本项目不能把第一阶段穿模当通过，也不能把“有碰撞惩罚”当“所有连杆均有严格安全约束”。本轮核查到的是预印本，不推断已被某会议接收。[R11]

需要的对比是同平台、同感知预算、同混合高度场景与同接触仪器下的结果。应优先获取作者可用实现；若只能独立实现类似的语义落足基线，必须命名 `semloco-inspired`，列出偏离，不声称官方复现。不能为证明新方法而故意削弱其非足端惩罚或训练预算。

### 4.2 与全身优化：几何对象和时间连续性才是关键

已有方法将身体、落足和摆腿纳入规划，但“联合考虑”有不同层级：身体包络、足端轨迹、连杆包络、实际碰撞网格，以及接触/动力学可行性。某种静态距离约束成立，并不代表执行中的跟踪误差、地图误差和关节插值运动全部安全。论文必须逐项说明覆盖范围。[R01][R02][R04][R06][R09]

本项目现有 `Capsule` 数值工具只对声明的静态距离场和线性端点运动给出保守界。它不是已经实现的 USD 全身运动规划器；没有实际连杆资产覆盖审核前不能称为 full-body guarantee。

### 4.3 与视觉记忆：别把“加 GRU / 体素记忆”当创新

NVM 已经利用过去视角推断当前身体下方环境，显式三维几何对齐也已有先例。野外感知运动还展示了循环感知融合。因此候选机制必须回答：哪些观测老化会改变哪条腿的风险预算？为何不是简单扩大所有障碍即可？在相同停顿时间和计算预算下是否仍然有效？[R12][R13]

### 4.4 与 DTC：先做好强控制基线

高层选择安全落点，如果低层跟踪误差大于间隙余量，规划改进不会转化为物理成功。DTC 说明规划参考与学习跟踪能结合；项目应测实际跟踪误差分布，再决定用现有跟踪器、重新训练或残差修正，而不是首先同时训练感知、规划和电机控制。[R14]

### 4.5 与跑酷和语义导航：评价目标必须统一

跑酷强调快速完成障碍技能，语义导航常在身体路线层面工作。它们是能力来源与外围基线，不宜用不同任务成功率直接宣布优劣。本项目奖励不能让“永远停止”获得最好结果，也不能让“撞开障碍但到达”变成严格成功。[R03][R08][R15][R16][R17]

## 5. 工程复用审计

本轮直接读取 Isaac Lab v2.3.0 的 `unitree.py`、Go2 flat 环境配置和 DirectRLEnv 示例接口。使用其内置资产配置，未复制 USD、模型权重或论文图。资产源配置默认关闭 self-collision，本项目评测适配显式请求开启，实际接触过滤仍须本地验收。

作者仓库被找到不代表可运行、训练权重公开或许可允许再分发。账本中的 `code_reproduced=false` 对全部论文成立。下一轮按优先级审计 SemLoco、全身优化/3D受限空间方法、NVM、DTC；记录依赖、权重、资产许可证、随机种子、可复现实验和失败。暂不承诺所有方法在同一 GPU 上的成本。

## 6. 修订论文主张

拒绝使用：首个四足保护易损物品、首个三维记忆、首个全身规划、单张狗截图证明动物机制、已有方法都只能点到点、不需要基线即可确定顶刊创新。

可检验的候选：在统一的混合高度细障碍协议中，**观测时效与全连杆风险约束的耦合**是否比强语义落足/几何规划基线更有效。需要消融、误差归因和真机证据；详见 [研究方案 v2](RESEARCH_PLAN_V2.md)。
