# 系统设计入口（v2）

当前完整架构与接口状态见 [研究方案 v2](RESEARCH_PLAN_V2.md)，物理实现细节见 [Isaac Lab实施](ISAACLAB.md)。启动期设计保留在Git历史，不再维护互相矛盾的仿真后端说明。

数据流：场景manifest → Isaac动态刚体/机器人 → 每步状态和接触 → append-only trace → 摘要 → 独立评测工具。感知参考路径：相机深度+光学位姿 → 点云 → 带年龄的局部体素记忆；该路径尚未接入运动actor。控制参考路径：oracle场景 → 保守机身路线 → 速度命令 → 用户提供且契约一致的TorchScript低层策略。

计划主方法需要在感知与控制之间增加实际全连杆几何、FK/IK、联合身体/四足/支撑时序优化和跟踪风险评估；这些尚未完成。原始几何capsule检查只覆盖声明的运动模型，不得把数值工具称为完成全身规划。

当前所有Isaac执行固定为oracle，不存在隐式`onboard`开关。日志里camera-enabled只说明采集了相机数据，不能改变信息权限。部署/训练的接口隔离标准见 [实验协议 v2](EXPERIMENTS_V2.md)。
