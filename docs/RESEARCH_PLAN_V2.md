# 研究方案 v2：面向论文的完整研发路线

2026-10-04，第 1 轮调研/工程迭代。本文是当前路线的主文档，优先于启动阶段文档中“仿真尚未选型”的描述。**Isaac Lab 为项目接口，Isaac Sim/PhysX 为底层仿真；最终机载感知能力、论文贡献与真机结果尚未实现。**

## 1. 最终目标不是演示，而是可证实的能力

在训练未见过的窄通道内混合摆放可被扰动的细杆、瓶罐、立木条和低矮块体。四足机器人仅利用机载感知与本体状态，自主选择前进、减速、短暂停看、后退重规划、身体姿态、足端落点和摆腿轨迹，完成跨越障碍区并稳定停下。评价同时要求不推开、不踩在被保护物体上、不越界、不依赖人工逐步指引。

目标分三层：工程上可运行可审计；能力上在留出布局有效且接触少；科学上通过强基线和因果对照解释某个机制何时有效。完成代码不等于完成任一后两层。研究不限定必须大模型、世界模型、端到端 RL 或动物模仿；硬件、预算与投稿 venue 尚待确认。

## 2. 形式化问题和困难分解

令状态 x 包含机身 SE(3)、关节位置/速度和接触状态；观测 o 包含带时间戳的图像/深度、本体测量与状态估计。环境 M 为未知的动态刚体集合，物体本来静置但接触后可以移动。策略根据观测历史产生动作，不得读取部署时不可得的物体真值。

规划候选包括机身轨迹 B(t)、足端轨迹 F_i(t)、关节轨迹 q(t) 和支撑时序。目标不是只满足终点脚位置安全，而是对每个机器人碰撞连杆 l、每个被保护对象 j、全部执行时间 t，保持足够净空，并满足关节/力矩/支撑约束。正常足端支撑地面是允许接触，其他接触需明确分类。

核心误差预算（候选设计，不是已证明概率界）：

    required_margin = geometry_error + localization_error
                    + tracking_error + observation_age_allowance

这些项必须通过误差标定或保守界获得，不能随手设置“3 sigma”就宣称安全概率。未观测空间单独表示 unknown；不能把没有看到障碍当成没有障碍。身体包络、足端和腿段分别有不同的几何覆盖与执行误差。

难点按接口分为：细杆能否被看到；见过但被遮挡后是否仍有有效信息；身体与足端路线是否几何可行；关节插值是否让膝部扫到杆；跟踪误差是否吃掉净空；碰撞/轻微扰动是否真的被仪器记录。必须先定位哪层主导失败，再设计学习机制。

## 3. 候选科学机制与可否证假设

### H1：足端安全不足，需要全连杆运动约束

在相同输入地图、候选数量、控制器、场景和预算下，比较“只选落足”“检查足端摆动”“检查所有连杆和躯干扫掠”。预期差异应集中在中高细杆、侧向窄缝与腿段碰撞，而非仅在到达速度。若收益只来自更大静态膨胀，不能归因全身协调；增加等效膨胀基线。

### H2：时空记忆的价值取决于它怎样影响决策

记忆本身已有 NVM 等先例。比较当前帧、固定保留时长的对齐记忆、显式观测年龄/位姿不确定性的记忆。三个版本用相同传感器、控制器、模型容量和运行预算。主分析按遮挡时长、后腿区域、细杆可见性分层。若只延长观察或降低速度就取得同等收益，应降低论文对机制的主张。

### H3：风险感知的观察动作只在有证据时加入

暂停、俯仰观察、后退可能改善视觉，也可能只是保守拖慢。主动观察不是当前必须上线的模块；先固定感知验证 H1/H2。以后至少比较同耗时减速、定时停顿和随机观察动作，报告额外观测、时延与成功率，而非只展示一段好看的行为。

### 拒绝的主张

不声称首个无碰倒四足、首个三维记忆、首个规划结合 RL，也不预先承诺某期刊。SemLoco、NVM、DTC、全身优化等是必须正面处理的先例，详见 [调研](RELATED_WORK.md)。

## 4. 单一主线的架构

**观测 → 局部几何/可见性记忆 → 身体/落足/摆腿候选 → 全身与动态可行性筛选 → 已验证跟踪控制器 → 仿真/机器人。** 独立评测器只读日志，不给 actor 泄露真值。

| 层 | 当前输入输出与实现 | 尚需补全 |
|---|---|---|
| 场景 | seed/split → 动态刚体 manifest + hash；已实现 | 与真实杆/瓶材质和尺度对齐，几何可行 witness |
| 感知 | 深度/内外参 → 世界点；点/时间 → occupied/free_observed/unknown；CPU参考已实现 | 实测误差、运动补偿、估计位姿、GPU性能、actor接入 |
| 几何 | 原始体 SDF、静态/线性扫掠 capsule 界、支撑多边形；已实现 | 实际 USD 全连杆覆盖、FK/IK、关节轨迹非线性界、动力学 |
| 规划 | 保守机身 A*、候选落足和足端摆动；已实现为弱诊断基线 | 联合身体/四腿/步态规划，优化强基线，记忆驱动决策 |
| 控制 | 默认关节 PD 站立；严格元数据约束的外部 TorchScript 速度策略接入 | 验证 checkpoint、精确足端跟踪，必要时学习残差 |
| 仿真 | Isaac动态场景、接触回调、相机、单回合执行与数据落盘；代码已写 | 本地 GPU/Kit 的实际运行和物理标定 |
| 评测 | 全程扰动最大值、禁止接触、缺测状态、原始日志一致性审核；已单测 | 仪器灵敏度、真实误差、独立人工抽查 |

现有机身 A* 把障碍全部投影到地面，不能跨过低矮块，故是故意保守且容易解释的弱基线；找不到路径不证明四足任务无解。现有 `VoxelMemory` 不是 NVM 复现，也不是最终不确定性推理系统。

## 5. 学习应放在哪一层

初期复用明确控制接口的稳定低层，使高层规划失败和电机控制失败可分离。只有在已测得跟踪误差主导失败时，才训练精确跟踪/残差策略。现有 `isaac_baseline_train.py` 仅启动上游 Go2 平地速度控制基线；它**不是**本项目密集障碍 RL 环境，也不产出本文最终方法。

计划中的学习输入：局部地图及可见性/年龄、局部机体状态、足端参考与相位；输出是有界参考修正或动作。特权真值可以仅用于 critic/teacher，但评测 actor 接口必须排除真值。冻结 teacher 数据生成版本，分别记录 teacher可行性、学生误差、实际接触。不得在评测中继续使用 teacher真值，却把结果标机载视觉。

不在本轮假造 PPO 训练完成，不下载来源不明权重，不建立多个互不验证的大型训练分支。候选学习环境与最终强控制器将在 M1/M2 后根据失败数据实现，而非用一个空 `train()` 函数装作齐全。

## 6. 按论文开发而不是按“代码数量”推进

| 阶段 | 交付与进入条件 | 完成/停止条件 |
|---|---|---|
| M0 任务/证据 | 任务协议、研究假设、来源矩阵、评测器 | 已有；本轮补入强近邻并收紧主张 |
| M1 物理与仪器 | Isaac单环境、实际资产清单、脚/腿/机身/墙/自碰撞测试、物体静置漂移、细杆时间采样 | 代码已交付；所有物理验收待本地；未通过禁止训练 |
| M2 强 oracle 基线 | 无感知误差地图、慢速稳定跟踪、全身可行轨迹、全程审计 | 测清轨迹误差与几何净空；单纯A*不满足该门槛 |
| M3 机载感知闭环 | 传感器模型、状态估计、可见性记忆、真值隔离 | 在相同布局比较oracle与sensed；未过不谈sim2real |
| M4 机制实验 | H1/H2、强近邻、公平预算、分层分析 | 有效则保留；负结果则收窄论文，不事后重写成功阈值 |
| M5 真机论文 | 场地、急停、标定、留出试验、独立复核、可复现材料 | 原始证据支撑每一项结论；不承诺录用 |

代码可以提前搭好接口和数值模块，但阶段通过只能依靠运行证据。允许主动停止无价值路线：例如细杆在可用相机里长期不可见时，先解决观测条件或明确更换传感器，不靠扩大训练量掩盖不可观测性。

## 7. 硬件和算力决策

Go2 是为了利用官方配置的仿真参考，不是对用户真机设备的认定。不得自动继承无人机项目的 Jetson、IMX900 或 16 GB GPU。先记录本机 Isaac可用版本、显存、资产、相机、SDK控制权限。单环境、低分辨率检查通过后再增加并行数；RGB-D RTX渲染与接触矩阵显存须实际测量。

任务场景按身体宽度、腿长、足半径、最小净空归一化，同时给出真实单位。不能从狗截图推断确切厘米数。细杆 diameter/pixel、近距盲区、机身遮挡、后腿视域是传感器选型输入，不预先认定一种相机足够。

## 8. 论文组织与结果表

暂定工作标题：**Contact-Sensitive Quadruped Traversal through Dense Mixed-Height Clutter**，不是已发表标题。Introduction 从“保护环境而非仅保持不摔”引出，Related Work 正面讨论 SemLoco/全身优化/NVM/DTC；Method 只写真正实现且有效的模块；Experiments 先仪器/可行性，再强基线与消融，最后真机泛化和失败。

主结果表必须同时给到达、无扰动、观测无禁止接触、未知/中止数；机制表按足端/小腿/大腿/机身/自碰撞细分；误差表含地图、跟踪、时延和观测年龄；预算表列训练时间/设备、推理和峰值显存。不给没有测量的栏填0或“实时”。实验安排见 [实验规范 v2](EXPERIMENTS_V2.md)。
