# 当前研究假设

以 [研究方案 v2](RESEARCH_PLAN_V2.md) 的H1/H2/H3、[实验 v2](EXPERIMENTS_V2.md) 的基线/负控制为正式定义。

H1：在相同地图和跟踪器下，全连杆扫掠约束在混合高度细杆中比仅落足/足端检查更有效；需排除单纯扩大静态padding。

H2：显式观测时效和误差如何影响连杆风险，比单纯添加几何记忆更重要；需和NVM等已有记忆思想及同预算固定记忆对比。

H3（可选）：主动观察优于同耗时减速/定时停顿；只有H1/H2初步证据成立后考虑。

全部仍为hypothesis，不是实测结论。SemLoco已有保护低矮易损物品研究，DTC已有规划结合学习跟踪，既有全身规划和NVM意味着这些单独概念不能充当本项目创新。
