# 项目章程

版本 0.1 · 2026-10-04 · 研究任务已经明确，最终算法尚未选定。

## 1. 用户希望看到的最终效果

四足机器人进入一个此前未见的密集障碍通道；前方、侧方和脚下分布细杆、木条、木块和瓶罐，通道不能从外侧绕开。机器人不只是让机身穿过，还要把每只脚放在空隙里，让足端、膝部、腿段、机身及附加传感器沿途都避开物体。空间不明确时可以停下来观察、缩短步幅、改变机身姿态或后退重规划，最终在终点区域稳定停下。

这是**任务能力对齐**，不是照着狗的单帧图重现一个动画。机器人形态与狗不同，最终场景按机体/足尺寸归一化，不要求复制无法从截图准确量出的尺寸。

## 2. 目标层级

工程成果：可运行的仿真到真机闭环、可重建的场景、可审计的失败记录。

能力成果：在留出布局上完成任务，提供无干预、低扰动、全身接触的分项证据。

科学成果：证明某个机制确实改善了感知受限情况下的全身精细穿越，并解释收益来自哪里、何时失效。

论文是明确最终目标；目前没有确认投稿会议或期刊，不承诺某个级别的录用。

## 3. 已确认与未确认

已确认：四足机器人；图示任务方向；建立持续维护的 GitHub 项目；最终产出论文。

工作默认（可经决策记录修改）：独立公开仓库（项目发起人已明确授权）；初期静态障碍、平地、慢速行走；优先比较可解释全身规划基线；先不依赖大模型和动物动作捕捉。

未确认：机器人型号和 SDK、相机/LiDAR、机载算力、训练 GPU、经费、工期、场地、团队人数、论文 venue。Go2 只是潜在平台，不是用户已拥有的设备。

## 4. 不允许偷换的目标

- 靠遥控或逐步人工给落点通过，不是自主闭环。
- 只保证机身路径不碰撞，不是全身穿越。
- 物体没倒，不能推断足端没有轻碰。
- 沿障碍区外侧的宽通道绕行，不代表图示能力。
- 只在训练过的固定布局成功，不能声称泛化。
- 用真值深度/场景坐标而宣称机载传感器部署，属于证据混淆。

## 5. 最小论文问题（候选表述）

“在局部观测、遮挡和几何误差下，如何把可落脚区域与全身运动扫掠空间联合起来，使四足机器人在易扰动物体间可靠穿越？”

这只是候选问题。是否具备独立创新性，必须通过相近工作精读、同口径基线和消融再决定。
