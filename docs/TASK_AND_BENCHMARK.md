# 任务与基准 v0.1

## 1. 场景定义

参考截图可见狭窄室内走廊，竖直细杆、长木条、低木块和不同尺寸瓶罐混合摆放。对象数量、真实尺寸、稳定性与狗的完整行为没有从单帧测得。以下参数是**拟议实验设计，不是截图测量结果**。

主轨道：平坦防滑地面、静态但可被扰动的障碍，封闭侧向边界、指定起终点区域。障碍可跨越但不可接触或作为支撑。允许改变步态、步长、步频、机身姿态、停看和回退；不允许整体跳过场地、人工移动障碍、遥控导航、从边界外绕行。动物模仿并非必要条件。

任务目标既包含移动，又包含对环境的保护。“易扰动”表示容易移动/倾倒，不要求使用易碎或危险材料。

## 2. 几何难度，而不是只数障碍

记录机身长宽高、站姿宽、足端尺寸、腿段体积、关节/扭矩范围和传感器突出尺寸。将通道宽度/机身宽度、落脚余量/足端宽度、杆径/足端宽度、障碍高度/有效抬腿高度作为无量纲指标；另记录单位面积数量、自由地面比例、遮挡比例和可行动作序列数量的估计。

建议开发层级：

| 级别 | 目的 | 准入条件 |
|---|---|---|
| D0 | 无障碍、单杆和单瓶 | 接触/位姿监测可靠，控制器稳定 |
| D1 | 少量障碍、充足空间 | 四脚落点、摆腿与机身状态能完整记录 |
| D2 | 混合高度/宽度，缩小落脚余量 | 存在经验证的全身可行路径 |
| D3 | 密集随机细杆瓶罐，后腿遮挡 | 必须联合身体、摆腿与落脚；不能外绕 |
| D4 | 留出材质/光照/传感器噪声 | D3 达标后扩展，不一开始全部训练 |

最终尺寸以机器人实测能力确定。不是越密越有学术价值；若无几何可行解，则不能将失败归因于算法。

## 3. 可行性分类

每个场景标记 `witness`、`infeasible` 或 `unknown`。`witness` 需要存储参考全身轨迹及动态回放证据，不是只找到一条中心线路径。规划器超时只能是 unknown，不得自动标 infeasible。构造式场景可以先采样安全全身轨迹再摆放障碍，但参考轨迹不得泄漏给测试策略。另设独立布局生成器检查构造偏差。

物理不可行场景用于“正确停止/拒绝”测试，必须与可行场景成功率分表报告。改变机器人几何后需重新评估可行性。

## 4. 成功必须拆成三种

令 C 表示：所有机器人部件进入目标区域、在限定时间内稳定停下、无跌倒、无越界、无人工介入、无禁止的空中跳跃/障碍支撑，且回合记录完整。

令 E 表示：全部待保护物体在整回合内未倾倒，最大平移与旋转未超过预注册测量阈值。

令 Z 表示：整回合未检测到任何禁止接触。允许四只脚与规定地面的正常支撑接触；脚碰瓶子、腿碰杆子、机身碰墙、附件碰物体、非足部触地、自碰撞均不允许。

- 到达成功：`S_completion = C`。
- 环境保持成功：`S_non_disturbing = C ∧ E`。
- 严格观测成功：`S_strict = C ∧ E ∧ Z`。

S_strict 是在已说明传感器覆盖和阈值下的“未检测到接触”，不是物理意义的绝对零接触证明。接触监测缺失不能认定 Z；位姿监测缺失不能认定 E。若已观测到失败，即便有缺测，该指标仍为 false；其余情况用 null/unknown。

停着不碰撞、到终点后跌倒、计时结束前碰倒再复位，都不能通过严格评测。物体扰动看**全程最大值**，不能只比较起终点。

## 5. 诊断与部署分轨

`oracle`：可读取真值，用于几何/控制上限诊断。不是机载自主能力。

`onboard`：仅现实中可获得的机载传感器、本体状态、给定目标与自建地图，禁止场景真值、未来帧、外部定位信息直接输入策略。若使用外部定位，只能另报 assisted 轨道；本版评测器尚未支持该扩展，不能伪装 onboard。

`synthetic_fixture`：人工造出的评测单元测试数据，不是机器人轨迹。

训练可使用 privileged 信息，但最终 actor 接口必须隔离。仿真中即使 observation_mode=onboard，也只能称传感器受限仿真，不能称真机部署。

## 6. 机器可读配置边界

`configs/benchmark_v0_1.json` 是初始评测配置：时限 120 秒、物体最大移动 5 mm、最大转角 2°。这些是检查软件的**暂定数值**，须在平台、传感器与空场噪声标定后正式预注册，不能直接作为论文结论阈值。允许接触的足端名称也须与最终资产一致。

接触传感器阈值、目标区域尺寸、稳定时长、时间同步容差、碰撞安全余量等仍待硬件确定。后续采集器应把这些写入新版本配置；当前评测器接收已经按协议计算的事件和摘要，不声称实现了这些底层计算。
