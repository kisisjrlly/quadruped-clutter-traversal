# 研究假设与可证伪设计

**研究任务不等于创新点。** 现有全身规划、碰撞避免、视觉落脚和不碰倒障碍已有先例；参见 RELATED_WORK.md。不能把“像狗”“用了强化学习”“做了三维地图”“加了碰撞惩罚”单独作为贡献。

## H1：身体、摆腿、落脚联合推理比只规划机身或只优化落点更有效

比较同观测、同底层控制器下的 B1 机身路线、B2 机身+落点、B3 全身摆腿联合约束。主观测量：严格成功率、被碰撞的连杆分布、最小全身净空、耗时。若收益在降低速度或调整常规基线后消失，不支持该机制是独立贡献。此方向已有强先例，单纯实现它通常只是基线。

## H2：局部几何记忆与不确定性处理能减少后腿和遮挡区域的错误

候选方法：将观测转换到统一时空参考，显式保留 occupied/free/unknown 及置信度；按实际连杆扫掠空间检索风险。比较单帧、历史但不补偿运动、运动补偿历史、不确定性版本。用受控遮挡与地图延迟测试，不只比较网络大小。

对照：相同参数量、相同历史长度、相同延迟预算；传感器 dropout 和偏置在相同物理初态上配对。若只要多加一个廉价相机就消除问题，需比较系统复杂度，并相应缩小算法主张。

## H3：为“下一步能看清”而调整动作，比被动保守更有价值（可选）

只有在 H2 后仍有证据表明观测不足限制穿越时开展。机器人能停看或改变姿态不代表主动感知有效；必须在总时间预算相同的条件下，与减速、固定观察动作、额外相机等基线比较。视角变化不能偷偷改变障碍真值、初态或可行性。

## 候选论文主线

优先考虑“感知不确定性下，以全身运动扫掠空间为对象的接触风险推理”，不是一次加入全部模块。最终贡献由实证决定，可能聚焦表示、规划耦合、感知动作选择之一。

## 机制归因与停止条件

- 地图真值下也做不到：先解决几何与控制，不训练视觉大网络。
- 几何可行但底层无法跟踪：修改控制接口、轨迹时标或机器人能力范围。
- oracle 明显优于 onboard：做薄障碍可见性、遮挡和时空同步诊断。
- 仅弱基线失败：先加强/调参基线，不宣称创新。
- 仅单布局有效：不足以支持泛化主张。
- 概念已由新文献覆盖：缩小或更换机制主张，不把题目换成“首次”。

每项 hypothesis 在 paper/claims.csv 中有状态。先记录预测再跑留出测试；负结果同样保留。
